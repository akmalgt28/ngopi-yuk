# ☕ Ngopi Yuk - Coffee Tracker

Sering lupa sudah berapa gelas kopi hari ini? Atau kaget lihat dompet menipis karena kebanyakan nongkrong di coffee shop? **Ngopi Yuk** adalah aplikasi tracker kopi simpel yang membantu kamu memantau asupan kafein, kadar gula, hingga pengeluaran harianmu.

Dengan tampilan yang *clean* dan modern, Ngopi Yuk dirancang agar kamu bisa mencatat aktivitas ngopimu hanya dalam hitungan detik.

---

## ✨ Fitur Utama

*   **⚡ Pencatatan Otomatis & Cepat:** Pilih jenis kopimu (Latte, Americano, dll), dan aplikasi akan otomatis menghitung estimasi kafein dan gula.
*   **🔥 Jaga Streak-mu:** Jangan kasih kendor! Pantau konsistensi kamu dalam mencatat kebiasaan harian.
*   **📊 Analitik & Grafik:** Lihat tren mingguan dan bulanan. Pantau jumlah gelas dan total pengeluaran lewat grafik yang intuitif.
*   **📅 Kalender Riwayat:** Cek kembali riwayat konsumsi kopi kamu melalui fitur kalender interaktif.
*   **🔔 Pengingat Harian:** Notifikasi pintar untuk memastikan data kesehatan dan keuanganmu tetap akurat setiap hari.
*   **🔒 Privasi Prioritas Utama:** Menggunakan pendekatan *Offline-first*. Semua data disimpan di perangkatmu sendiri, kami tidak menyimpan data di server mana pun.
*   **💾 Backup Aman (JSON):** Mau ganti HP? Ekspor dan impor data kamu dengan mudah dalam format JSON.

## 🛠️ Cara Instalasi

Ikuti langkah-langkah di bawah ini untuk menjalankan project secara lokal:

**1. Clone Repositori**
```
git clone [https://github.com/username-kamu/ngopi-yuk.git](https://github.com/username-kamu/ngopi-yuk.git)
cd ngopi-yuk
```
**2. Install Dependensi**
Pastikan kamu sudah menginstall Node.js dan Ionic CLI.
```
npm install
```
**3. Jalankan Aplikasi**
```
ionic serve
```
Aplikasi akan terbuka secara otomatis di browser pada alamat `http://localhost:8100`.

## 🎯 Mengapa Ngopi Yuk?

Cocok buat kamu yang ingin:

1. **Membatasi Kafein:** Menjaga kesehatan jantung dan pola tidur.
2. **Diet Gula:** Memantau asupan gula dari campuran kopi susu atau sirup.
3. **Budgeting:** Mengatur budget jajan kopi bulanan agar dompet tetap aman.
